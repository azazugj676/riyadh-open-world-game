# لعبة الثعبان (Snake) - تجربة بسيطة

هذا المستودع يحتوي على لعبة ثعبان بسيطة تعمل في المتصفح باستخدام HTML و CSS و JavaScript فقط، بدون أي مكتبات خارجية.

الملفات:
- index.html: صفحة اللعبة الرئيسية وتضم canvas لعرض اللعبة.
- style.css: أنماط الصفحة وتصميم واجهة اللعبة.
- game.js: منطق اللعبة (حركة الثعبان، الطعام، التصادمات، إعادة التشغيل).

كيفية التشغيل:
1. حمّل أو استنساخ المستودع إلى جهازك.
2. افتح الملف `index.html` في متصفح حديث (Chrome, Firefox, Edge...).

قواعد اللعب:
- الهدف: أكل أكبر عدد ممكن من العناصر (الطعام) لزيادة طول الثعبان والحصول على نقاط.
- التحكم: استخدم مفاتيح الأسهم (↑ ↓ ← →) أو W A S D لتحريك الثعبان.
- تنبيه: لا تتجه بعكس الحركة الحالية مباشرة (مثلاً إذا كنت تتحرك لليمين لا يمكنك التحول مباشرة لليسار).
- عند الاصطدام بالحائط أو بجسم الثعبان تنتهي اللعبة.

زرّ "إعادة التشغيل" لإعادة بدء اللعبة بعد الخسارة.

ملاحظات:
- اللعبة مصممة لتكون بسيطة ومناسبة كتجربة أو لتوسيعها لاحقًا (إضافة مستويات، سرعات مختلفة، مؤثرات صوتية...).
- جميع الملفات مكتوبة بدون أي مكتبات خارجية.

بالتوفيق واستمتع باللعبة!
