أعلى نتيجة: 0

كيف تلعب؟

  • حرك الثعبان باستخدام الأسهم ⬆️ ⬇️ ⬅️ ➡️ أو أزرار W A S D أو بالسحب على الشاشة.
  • كل تفاحة تأكلها تزيد طول الثعبان وتمنحك نقاطاً (التفاحة الذهبية 🌟 = 3 نقاط).
  • تجنب الاصطدام بالجدران أو بجسم الثعبان.
  • اضغط زر "المسافة" (Space) لإيقاف اللعبة مؤقتاً.

لعبة الثعبان مصممة بـ HTML و CSS و JavaScript.
